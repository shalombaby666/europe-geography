# География Европы

[Открыть тесты](https://shalombaby666.github.io/europe-geography/)

Два автономных теста: найти страну на карте и выбрать столицу. Случайная выборка и порядок вопросов, обратная связь, итоговый счёт и повторный запуск. MySQL, серверная база и аккаунт не используются.

Откройте index.html либо `python -m http.server 8000`. На маленьких экранах карту удобнее открыть горизонтально. Маска проверяет территорию клика; у малых стран есть допуск.

## Карта
В экспорте Claude изображение и маска отсутствовали. Они восстановлены из Natural Earth, 1:50m Admin 0 Countries: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson
Условия: https://www.naturalearthdata.com/about/terms-of-use/ — public domain. Упрощённая учебная проекция, границы следуют набору данных и не выражают позицию автора. Изображение и маска имеют общую геометрию. Набор содержит 40 областей для теста.
